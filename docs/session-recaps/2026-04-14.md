## Key Decisions

- **Design system**: Used CLAUDE.md's cool-toned palette (navy/slate/white, Playfair Display + Inter) for the overall site, but kept the brief's exact gold (#8B7340) and charcoal (#1C1C1E) for the Easter Egg SVG portraits — the gold at 0.07 opacity is load-bearing for the Easter egg to read correctly
- **No Tailwind/Next.js**: Brief specifies Next.js + Tailwind but CLAUDE.md specifies React 19 + Vite + CSS custom properties. Built to CLAUDE.md stack
- **Attorney detail pages**: Modeled after Davis Polk's attorney bio layout (sidebar + main content) rather than the brief's simpler inline bios
- **Emerging entity types**: Added animatronic, mannequin, humanoid/android, and digital entity categories to the "Who We Serve" page — forward-looking practice areas
- **Puppet DNA**: Three subtle slips baked into the UX that the puppet developers "wouldn't notice" — entrance animation from above, "operating" language, "production" terminology
